# 本地工作台使用说明

## 先准备输入

用户先按[用户使用说明](../docs/用户使用说明.md)创建项目并完成输入绑定。项目默认
保存在仓库内的 `projects/` 目录；也可以通过命令参数指定其他本地目录。

## 启动

在仓库根目录执行：

```bash
make start
```

等价命令是：

```bash
python3 view/serve_review_dashboard.py \
  --review-root projects \
  --host 127.0.0.1 \
  --port 8765
```

浏览器打开 `http://127.0.0.1:8765`。工作台只读取 `projects/` 中已经存在的项目；
它不会替用户下载论文、确认分子或把缺失证据变成通过。

## 当前版本能看到什么

- 已创建项目的输入状态、MAIN/SI 绑定和 provenance 状态；
- 有来源定位的证据、未确认候选和阻断原因；
- 后续阶段已经生成的草稿或发布状态（如果该项目确实具备这些新鲜产物）。

空项目或未完成项目显示为空缺/阻断是正常结果，不代表系统出错。
